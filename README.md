# UM-agBOT

## ROS 2 Environment Setup

This repository contains setup files for the University of Michigan AgBOT project.

### Setup Instructions

To set up the ROS 2 environment:

```bash
chmod +x ros2_setup.sh
./ros2_setup.sh
```

> **Note:** Building from source will take a significant amount of time. Consider using pre-built binaries when possible.
